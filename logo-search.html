IPTV Logo Repair — Buscador visual

Busca logos en los catálogos públicos de iptv-org, Jaruba y Yasserstudio. También puedes abrir Google Imágenes con una búsqueda orientada a logos de canales, por ejemplo «TNT logo canal png». Revisa el logo antes de elegir: que una imagen cargue no garantiza que sea correcta.

Si escribes «TNT», aquí aparecerán los nombres reales encontrados, por ejemplo «TNT HD» o «TNT Opc1». Selecciona el canal concreto para enviar su nombre exacto al workflow.

Pulsa «Buscar logos». La primera búsqueda descarga los índices públicos y puede tardar unos segundos.

Logo seleccionado


Luego, en el workflow «Gestionar logo manualmente», pega el nombre exacto del canal y la URL copiada. La regla se aplicará solo a esa variante.

Importante: este buscador solo lee catálogos públicos. No modifica la playlist ni guarda cambios directamente en GitHub. La aplicación se hace mediante el workflow autorizado; así no hace falta guardar un token de GitHub dentro de esta página.
